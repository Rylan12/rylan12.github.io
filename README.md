# My Personal Website

This repository contains the files behind [rylanpolster.com](https://rylanpolster.com/).

The design for this site is inspired by Matthew Butterick's website, [mbtype.com](https://mbtype.com/), and his book, [Practical Typography](https://practicaltypography.com/).

The font used throughout this site is Charter, designed by Matthew Carter. The font files that are distributed with this site are provided by Matthew Butterick and are available [here](https://practicaltypography.com/charter.html). The font is subject to its original license which can be downloaded [by clicking here](https://rylanpolster.com/assets/fonts/charter/LICENSE).
